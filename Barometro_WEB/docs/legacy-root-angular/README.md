# Angular legado de raiz

Esta carpeta conserva los archivos Angular que estaban ubicados directamente en la raiz del proyecto:

- `src/`
- `public/`
- `angular.json`
- `package.json`
- `package-lock.json`
- `bun.lock`
- `tsconfig*.json`
- `.prettierrc`

No forman parte del frontend activo. El frontend web vigente vive en `frontend/` y se ejecuta mediante los scripts de `scripts/`.

Mantener estos archivos archivados evita confundirlos con la aplicacion Angular 21 activa y conserva el historial para consulta o comparacion si hiciera falta.
